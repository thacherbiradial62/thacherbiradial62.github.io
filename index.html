⌨️ henry-keykey - 讓注音輸入更靈活與快捷

下載安裝檔案

Henry-Keykey 是一款針對 Apple Silicon 架構開發的 macOS 輸入法。此輸入法專為台灣使用者優化，提供流暢的輸入體驗。它支援繁體與簡體中文輸出，並具備兩岸常用詞彙庫。軟體擁有本機學習機制，能隨使用習慣記憶你的用語。

🚀 系統需求

在使用此輸入法之前，請確認你的電腦環境：

  • 搭載 Apple Silicon (M1, M2, M3 等系列) 晶片的電腦。
  • macOS 12.0 或更新版本。
  • 至少 200MB 的硬碟儲存空間。

📥 安裝指南

請依照下列步驟安裝此輸入法：

  1. 前往 官方下載頁面 下載最新的安裝套件。
  2. 下載完成後，點擊安裝檔案並依照螢幕指示完成設定。
  3. 打開「系統設定」，選擇「鍵盤」與「輸入法」。
  4. 點擊新增按鈕，將 henry-keykey 加入你的輸入法清單。
  5. 完成後，你即可在輸入文字時將輸入法切換為 henry-keykey。

✨ 主要特色

  • Apple Silicon 原生支援：程式運行速度快且節省記憶體。
  • 雙模式切換：支援一鍵切換繁體與簡體中文。
  • 智慧詞彙：內建兩岸詞彙庫，減少選字次數。
  • 本機學習：輸入法會記憶你常用的詞彙，提升輸入速度。
  • 離線優先：所有運算皆在你的電腦執行，確保隱私安全。

⚙️ 常見問題

問：為什麼無法輸入注音？
答：安裝完成後，請務必重新啟動瀏覽器或正在進行輸入的應用程式，系統才會載入新安裝的輸入法資源。

問：資料會發送到網路上嗎？
答：不會。此軟體強調離線優先，你的輸入習慣與個人詞庫僅會儲存於你的裝置內。

問：如何刪除個人學習紀錄？
答：你可以進入輸入法設定選單，選擇重置個人化詞庫來清除記憶資料。
