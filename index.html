🔍 What Is This Software?

This is a complete, ready-to-use security infrastructure package that turns any computer into a professional Security Operations Center (SOC). It automatically sets up:

  • SIEM (Security Information and Event Management) – Collects and analyzes security events from your entire network
  • EDR (Endpoint Detection and Response) – Monitors individual computers for malicious behavior
  • Fleet Management – Manages all security agents from one central dashboard
  • Threat Detection – Uses MITRE ATT&CK framework to identify attack patterns
  • Network Monitoring – Integrates Zeek to analyze network traffic in real-time
  • Encrypted Communications – All data transmission is protected with TLS security

Everything runs automatically using Docker containers – you don't need to configure anything manually. It's like having a team of security experts working 24/7 on your network.

🛠️ Key Features

🔐 TLS Security

All communications between components are encrypted using Transport Layer Security (TLS). This means no one can intercept or read your security data – it's the same encryption banks use for online transactions.

📡 Fleet Orchestration

Manages all your security agents centrally. Think of it like a control center that tells every security sensor exactly what to do, when to do it, and how to report back. It ensures everything works together perfectly.

🖥️ Endpoint Telemetry

Continuously collects detailed activity data from every connected computer – running processes, file changes, network connections, and user activity. This gives you complete visibility into what's happening on your systems.

🎯 ATT&CK-Aligned Detection

Uses the MITRE ATT&CK framework – the global standard for describing attacker behavior. The system knows what cyber criminals do and constantly watches for those patterns, catching attacks before they succeed.

🌐 Zeek Integration

Includes the powerful Zeek network analysis tool (formerly Bro). It monitors all network traffic in real-time, detecting suspicious patterns like unusual data transfers or malicious communication attempts.
